В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Пакет `db`отвечает за взаимодействие с PostgreSQL: подключение, инициализацию схемы и CRUD-операциями над задачами. Просто слой доступа к данным.

Пакет `service` содержит чистую функцию "NextDate", которая вычисляет следующую дату по правилу повторения.

Модуль `router.go` - точка сборки HTTP слоя. Создает `chi.Router`, регистрирует маршруты, подключает миддлвари и раздает статику.

Пакет `middleware` содержит 2 прослойки - одна для логгирования событий(запросы, коннекты, сигналы), другая для аутентификации - проверка JWT-токена и проброс `user_id` в контексте.

Пакет `handlers` является HTTP слоем. Принимает JSON, валидирует и вызывает `db.Store` или `auth.Manager` -> возвроащает JSON.

Пакет `auth` отвечает за JWT-аутентификацию с ОДНИМ паролем и ничего более. Только пароль из env, который обменивается на JWT-token.

Пакет `config` загружает настройки приложения из переменных окружения, только парсит env.
